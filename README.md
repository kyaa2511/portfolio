# Katana Yaa — Portfolio

Next.js (App Router), TypeScript, Tailwind CSS v4, Motion for React, Lucide.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript validation

## Structure

- `src/app` — routes, layout, global styles and design tokens
- `src/components/layout` — navigation, footer
- `src/components/sections` — homepage sections
- `src/components/ui` — shared primitives (Button, SectionHeader)
- `src/components/motion` — reusable animation components and variants
- `src/data` — typed content (projects, site copy)
- `src/types` — shared TypeScript types
